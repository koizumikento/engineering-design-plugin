# 機械設計で参照するJIS

## 使い方

この文書は規格本文の代替ではなく、公式カタログから現行状態と適用範囲を確認するためのsource mapである。公差表、はめあい数値、試験条件をこのリポジトリから規格値としてコピーしない。実案件では購入・閲覧権限のある規格本文、契約図面、メーカー仕様を確認する。

## 主な現行規格

| 規格 | 対象 | 状態確認時の注意 |
|---|---|---|
| JIS B 0001:2019 | 機械製図 | 部品図・組立図。2024-06-20確認 |
| JIS B 0405:1991 | 指示のない長さ・角度寸法の普通公差 | 金属除去加工または板金成形への適用。2025-06-20確認 |
| JIS B 0401-1:2016 / B 0401-2:2016 | サイズ公差、寸法差、はめあい | 呼び寸法と公差クラスを規格本文で確認 |
| JIS B 0021:1998 | 幾何公差表示 | 2023-10-20確認。関連する新しいGPS規格も案件ごとに確認 |
| JIS B 0601:2013 | 輪郭曲線方式の表面性状用語・パラメータ | 数値指定には測定条件・評価規格も必要 |
| JIS C 60529:2026 | 外郭による保護等級（IPコード） | 2026-01-20制定。JIS C 0920:2003の移行先 |

## 適用上の注意

- JIS B 0405の適用範囲をFDM/SLAなどの積層造形へそのまま拡張しない。工程能力、造形方向、材料、装置、後処理、測定方法から公差を決める。
- はめあい記号だけで機能は決まらない。温度、表面処理、潤滑、変形、組立方法、寿命を確認する。
- タップ下穴、ボルト穴、ざぐり、皿穴は、ねじ規格、締結部品の製品規格、工具、材質、ねじ込み長さ、工程から決定する。
- 表面粗さと加工方法を一対一で固定しない。機能面の要求と測定条件を記載する。
- build123d geometryは公差注記や検査方法を自動的には表現しない。図面/仕様/検証マトリクスを別途持つ。
- IP等級はCAD形状から認定できない。適用規格の試験条件と試験証拠が必要。
